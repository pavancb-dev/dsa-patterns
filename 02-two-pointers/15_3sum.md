# Two Pointers

## Recognition

Consider Two Pointers when:

- Array/string is sorted
- Need pair/triplet relationships
- Need to find a target sum
- Need to shrink/expand a search range
- A sorted order lets us eliminate candidates

## Core Idea

Maintain two indices representing the current candidate range.

Typical setup:

left = start
right = end

Use the ordering of the data to decide which pointer
can safely move.

## Sorted Two Sum

If:

nums[left] + nums[right] < target
→ left++

If:

nums[left] + nums[right] > target
→ right--

If equal:
→ found answer

## 3Sum

Sort first.

For each fixed `i`:

left = i + 1
right = n - 1

Now solve:

nums[left] + nums[right] = -nums[i]

This reduces 3Sum to repeated 2Sum searches.

## Why Sorting Helps

Sorting creates monotonic behavior.

Moving `left` can only increase the value.

Moving `right` can only decrease the value.

Therefore we can eliminate entire groups of impossible pairs.

## Duplicate Handling

For unique combinations:

1. Skip duplicate fixed values:

if i > 0 and nums[i] == nums[i - 1]:
    continue

2. After finding a valid combination, skip duplicate
   left/right values.

## Complexity

Two Sum on sorted array:

Time: O(n)
Space: O(1)

3Sum:

Time: O(n²)
Space: O(1) excluding output

## Invariant

For fixed `i`, `[left, right]` represents the remaining
candidate pair range.

Every pointer movement eliminates candidates that
cannot produce the target.

## Pitfalls

- Forgetting to sort
- Moving the wrong pointer
- Forgetting `left < right`
- Returning duplicate triplets
- Not skipping duplicate `i`
- Not skipping duplicate left/right after a match

## 10-Second Recall

Sorted + pair target
→ left/right

Too small → left++
Too large → right--

3Sum
→ sort
→ fix i
→ Two Sum on remaining range
→ skip duplicates.

### Python
```python
def three_sum(nums: list[int]) -> list[list[int]]:
    nums.sort()
    ans = []

    for i in range(len(nums)):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        
        left = i + 1
        right = len(nums) - 1

        while left < right:
            total = nums[i] + nums[left] + nums[right]

            if total == 0:
                ans.append([nums[i], nums[left], nums[right]])

                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1

                left += 1
                right -= 1

            elif total < 0:
                left += 1
            else:
                right -= 1
    return ans
